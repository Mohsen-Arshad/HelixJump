# HelixJump

A 3D **Helix Jump-style game** built with **Unity and C#**.

This project was created as a hands-on game development project, covering not only programming but also **3D modeling, animation, materials, and game design**.

## About

The game features a rotating tower of platforms where the player controls a bouncing ball and tries to reach the bottom while avoiding obstacles.

The project includes custom gameplay systems, animations, interactive platforms, scoring, camera control, and multiple visual elements.

## Features

* 3D Helix Jump-style gameplay
* Player movement and bouncing mechanics
* Rotating platforms
* Different platform types and colors
* Score and multiplier system
* Custom animations
* Camera movement and control
* Swipe-based rotation
* Game states and UI
* Custom 3D models and assets

## Created From Scratch

One of the main purposes of this project was learning the complete game development workflow.

I created the game's **3D models, animations, and visual assets myself using Blender**, and implemented the gameplay and systems in Unity with C#.

This includes:

* 3D modeling
* Animation
* Materials
* Gameplay programming
* Physics and movement
* Camera systems
* UI and scoring
* Level and platform design
